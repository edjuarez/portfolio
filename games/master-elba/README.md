# Master Elba

Master Elba is a browser-based arcade game developed with **Construct** as an academic project. The game challenges players to survive as long as possible while defeating enemies and achieving the highest score.

## 🎮 Gameplay

The objective is simple:

- Survive against continuous enemy attacks.
- Eliminate enemies to increase your score.
- Dodge incoming projectiles and avoid taking damage.
- Stay alive for as long as possible to achieve the highest score.

The game combines fast-paced action with precision aiming and movement, rewarding quick reflexes and strategic positioning.

## 🕹️ Controls

| Action | Control |
|--------|----------|
| Move | Mouse |
| Shoot | Left Mouse Click |

## 🚀 Features

- Arcade-style survival gameplay
- Mouse-based movement
- Click-to-shoot mechanics
- Progressive score system
- Pixel art graphics
- Lightweight browser experience

## 🛠️ Built With

- **Construct**
- **HTML5**
- **Pixel Art**

## 📚 Purpose

This project was created for academic purposes to explore game development concepts, including gameplay mechanics, collision detection, event-driven programming, scoring systems, and player interaction using Construct.
